MYTOURBAZAR V204 - NORTHFLANK DEPLOYMENT

1. Keep these files in the root of the GitHub repository:
   Dockerfile
   start.py
   requirements.txt
   bot.py
   ai_provider.py

2. Do not upload .env, __pycache__, API keys, or Telegram tokens to GitHub.

3. In Northflank, open the MyTourBazar combined/deployment service.

4. Open Environment and add the runtime variables documented in XKIRO_SETUP.md.
   Secrets must be runtime variables, not Docker build arguments.

5. Confirm these required assets remain in GitHub:
   assets/mytourbazar_footer2_clean.png
   assets/mytourbazar_footer.png
   assets/mytourbazar_watermark.png
   assets/mytourbazar_contact_bar_orange.png
   data/T&C NON GOOGLE.pdf
   data/B2B.pdf
   data/without_footer.pdf
   data/logo_default.png

6. Push the latest commit to the branch monitored by Northflank.

7. If CI/CD is enabled, wait for the build and deployment to finish. Otherwise,
   select the latest commit manually and deploy/restart the service.

8. Check Northflank build logs and runtime logs. Then test one Air Print,
   one Hotel Print, one scanned supplier file, and one detailed Tour PDF.

Required runtime variables:
   BOT_TOKEN
   AI_PROVIDER=xkiro
   XKIRO_API_KEY
   XKIRO_TEXT_MODEL=qwen/qwen3.5-plus:free
   XKIRO_VISION_MODEL=qwen/qwen3.5-plus:free

Optional controls and GROQ fallback variables are listed in XKIRO_SETUP.md.
